Stock Trading System

Project Description

Stock Trading System is a console-based Java application that allows users to view available company stocks and purchase stocks based on their available balance. Users can select a company, enter the quantity of stocks they want to buy, and the system calculates the total cost and remaining balance.

Features

- Display available companies and stock prices
- Enter user balance
- Select a company to purchase stocks
- Enter stock quantity
- Calculate total purchase amount
- Display remaining balance
- Show purchased company and quantity

Technologies Used

- Java
- ArrayList
- Scanner
- Object-Oriented Programming (OOP)

How to Run

1. Install Java JDK.

2. Download or clone this repository.

3. Open the project folder in VS Code.

4. Compile the Java file:
   
   "javac stockTrading2.java"

5. Run the program:
   
   "java stockTrading2"
